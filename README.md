# Digital Library of Anatolian Motifs

A generative, research-grounded digital library of Anatolian kilims. A simulated loom weaves a new specimen from a seed each time — regionally rooted, coloured with natural dyes — and presents it beside a browsable index of the motifs it is built from and the regions that weave them.

**Thesis: the handmade inside the algorithmic.** Real kilims are already pixel art on a warp-and-weft grid, and their motifs are generative within each family: a ram's horn is never the same twice, yet is always a ram's horn. The library treats that as the design rule. Every motif comes from the documented catalog; the generator only ever recombines what weavers actually wove.

## What is in it

- **No. 01 — Specimen of the loom.** The live p5.js generator: region → format → composition → palette → motif placements, rasterised to integer loom cells, then slit-weave gaps and optional cicim relief — a direct representation of the documented patterns. Every specimen carries an accession number and a citable seed (`?region=konya&seed=4827193` re-weaves it exactly). *Weave another*, *Save plate* (PNG), hover a motif for its museum label.
- **No. 02 — The motif index.** 28 catalogued motifs in 7 categories. Each opens to its meaning, the regions that weave it, and two kinds of variation: the same grid in the *regional dyes* of the regions that weave it, and the *documented forms* — 1,477 variants auto-traced from the printed catalog, lazily loaded and rendered through the same loom code path.
- **No. 03 — Weaving regions.** 20 regions with signature, dyes, favoured compositions and formats, and their motif pool linking back to the index.

## Run it locally

No build step. Serve the folder over http (ES modules and `fetch` need it):

```
python3 -m http.server 8000
# then open http://localhost:8000/
```

## How it is made

- p5.js (vendored in `vendor/`) and vanilla ES modules in `src/` — no frameworks, no bundler, no other dependencies.
- `src/rng.js` is the single seeded random source; nothing calls `Math.random()`.
- `src/motif.js` — grids as pixel masks; `renderMotif(pattern, primary, secondary)`.
- `src/weaverhand.js` — `weaverHand(pattern, seed, { handStrength, curvilinear })`, seeded hand-variations (kept in the codebase, not shown on the site for now).
- `src/composition.js` — interprets the ten composition zone-maps into borders, niches, bands, compartments and medallions.
- `src/loom.js` — paints the loom: slit gaps, cicim relief (the aging pass exists but is switched off).
- `src/generator.js` — orchestrates a weave.
- `data/` — the data layer (`motifs.json`, `regions.json`, `compositions.json`, `dyes.json`, `variants/*.json`), generated by `tools/build-data.py` from the motif library in `motifs/` and the research reference.
- `tools/` — the auto-trace pipeline (`autotrace.py`, `retrace.py`, `pages.py`) that produced the variant library from the printed catalog, the data build, and headless checks (`test-weave.mjs`, `shoot.py`, `plates.py`).
- `motif-editor.html` — the grid editor used to draw and correct motifs by hand.
- `preview.html` — a single-file copy of the whole library (built by `tools/build-preview.py`) that opens by double-click, no server needed.

Turkish terminology is preserved in identifiers; motif and region names are shown in their own language with an English gloss.

## Sources

Motif meanings, the regional catalog, palettes and compositions follow the project's research reference (`RESEARCH.md`), drawing on Mine Erbek, *Çatalhöyük'ten Günümüze Anadolu Motifleri* (T.C. Kültür Bakanlığı); Belkıs Balpınar & Udo Hirsch, *Flatweaves of the Vakıflar Museum Istanbul*; Güran Erbek, *Kilim Catalogue*; and Josephine Powell's field photography. Variant grids were auto-traced from the Erbek catalog and are marked *pending validation* in the index until each has been checked against the printed page. The printed page images are not part of this repository.

Nothing here is invented: every motif comes from the documented catalog.
